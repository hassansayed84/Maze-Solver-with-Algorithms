
Maze Solver with Algorithms

Description
This project demonstrates the implementation and visualization of three search algorithms, Depth-First Search (DFS), Breadth-First Search (BFS), and A* Search, for solving randomly generated mazes. Each algorithm has its own approach in finding a path from the start to the goal within a maze. This project uses Python with NumPy for maze generation, and Matplotlib for visualizing the search process and the solution path

Features

Maze Generation: Randomly generates a maze with availability to adjust the size and obstacle density.

Search Algorithms:

-Depth-First Search (DFS): Explores as far as possible along each path before backtracking due to an obstacle.

-Breadth-First Search (BFS): Explores all neighbors at the current depth before moving to the nodes at the next depth level.

-A*: Uses a heuristic to prioritize nodes that are calculated to be closer to the goal

Visualization: Animates the search process for each algorithm, which shows how the path is explored and the final path to the goal.

Performance Evaluation: Displays the path length, nodes expanded, and execution time for each algorithm, after each run. Also shows the average of the 10 runs.
